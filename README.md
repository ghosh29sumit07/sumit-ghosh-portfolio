# Sumit Ghosh — Portfolio Recreation

This project recreates the visible portfolio website shown in the supplied reference video:
- black cinematic background
- yellow handwritten "The portfolio" presentation style
- "PRAVARIKA" hero
- open-to-work badge
- Java/Grails/Jenkins/Python/AWS chips
- profile image panel
- numbered navigation
- glassmorphism brown/black cards
- WHO I AM card
- TECHNICAL SKILLS card
- PROJECTS
- BY THE NUMBERS
- scroll-triggered card entrance animation
- animated counters
- responsive mobile layout

The supplied video is a screen recording of the site on a laptop, so the laptop keyboard/browser frame is not part of the actual website. The source code recreates the webpage itself.

The extracted image in assets/reference-portrait.jpg is taken from the user-supplied reference video as a temporary visual reference. Replace it with your own portrait for a personal portfolio.

Run:
1. Open the folder in VS Code.
2. Use Live Server.
3. Open index.html.

Customize the name, email, project text, social links and profile image.
